# Download

For the **SkyRoof / WSJT-X / IC-9700 / Remote Control Switch** features
described in this fork's documentation, use builds from
[Iu-yang1/SkyCAT GitHub Actions](https://github.com/Iu-yang1/SkyCAT/actions)
or [Iu-yang1/SkyCAT Releases](https://github.com/Iu-yang1/SkyCAT/releases)
when a release is available. A successful Windows workflow may publish a
`skycatd-wsjtx-win-x64` artifact; check the specific run for the latest build.

Upstream (VE3NEA) releases:
[VE3NEA/SkyCAT Releases](https://github.com/VE3NEA/SkyCAT/releases).
Upstream releases **must not be assumed** to contain the fork-only
TCP 4534/4535/4537 interfaces.

See [skycatd command-line options](skycatd.md) and the
[IC-9700 Remote Control Switch integration guide](skycatd.md#ic-9700-remote-control-switch-integration).
